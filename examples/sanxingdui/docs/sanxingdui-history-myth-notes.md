# 《三星堆：古蜀的回声》资料与艺术边界

2026-10-10。72秒，1080P，Remotion二维插画动画。

古籍晚于三星堆年代，不能直接当作该时代的现场记录。蚕丛与纵目面具、鱼凫与鱼鸟纹、神树与扶桑或建木之间的关联均不作为已证实事实。丰收祈愿、鸟携愿望飞向天空、建筑布局、服饰与动作属于本片想象。没有混入金沙太阳神鸟金饰，没有使用外星人或超自然历史断言。

所有画面为简化插画，金杖鱼鸟纹不是精确摹本；神树为三层九鸟示意并添加简化龙形构件。日轮、星空、自由飞行的鸟是神话意象，不是出土文物的动态演示。环境声音为合成氛围。
